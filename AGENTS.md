# Maintaining this guide

- Keep product facts tied to current official OpenAI documentation and a verification date.
- Label scenario routing as this guide's recommendation; do not invent benchmark results.
- Keep Chat, Work, local Codex and API configuration distinct.
- Preserve accurate image provenance. A requested model name does not prove the backend model.
- Run the repository validator after changing links, agent templates or images.
- Run installer tests after modifying installation behavior.
- Preserve original user files and existing account configuration.
