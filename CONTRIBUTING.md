# Contributing

Corrections should identify the affected passage, the current official source, and the date verified. For a new task recommendation, explain the task boundary, model choice, escalation trigger and observable completion check.

Do not present one successful run as a general benchmark. Include representative cases and failure analysis if proposing a measured performance claim. Keep private prompts, customer information and credentials out of issues and patches.

Run `python scripts/validate.py` before submitting. Run `python scripts/test_installer.py` if installation behavior changes. Image additions need useful alt text, a clear purpose and truthful provenance.
