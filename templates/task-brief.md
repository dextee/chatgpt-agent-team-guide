# Delegated task brief

Fill in the brackets, attach the inputs, and give this brief to the person or agent that owns the work.

```text
Produce [deliverable and format] for [reader or use].
Use [files, records, sources or base revision]. Apply [settled decisions].
You own [files, records or research question]. You may [permitted actions].
Coordinate [shared dependency] with [owner] before changing it.
The deadline or usage limit is [limit, if any].
The result is acceptable when [specific behavior or comparison passes].
Return [artifact or location], the checks you ran and unresolved items.
If another agent participates, identify its actual task and result.
```

## Example brief for a reviewer

```text
Review the attached meeting note and draft action list for the project lead.
For each commitment, compare the task, owner and due date with the source
sentence. Mark information missing from the note as "not stated." List
omitted commitments and quote the sentence that supports each correction.
Return the corrected action list here. This assignment covers review only.
```
