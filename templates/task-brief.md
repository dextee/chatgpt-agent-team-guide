# Delegated task brief

## Outcome

State the concrete result and who will use it.

## Inputs

List the relevant sources, base revision, definitions and prior decisions.

## Ownership

Name the agent and its files, browser session, external record or research question.

## Constraints

State the authorized scope, timing, quality bar and usage budget if any.

## Acceptance

List observable evidence that would establish completion.

## Return

Provide the result, evidence, verification performed, unresolved issues and next action.
